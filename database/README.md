# EduVerse Database

This directory contains the database design and database-related resources for the EduVerse platform.

## Purpose

The database will store and organize the information required for EduVerse to operate.

## Main Data Areas

The planned database will contain information related to:

- Users
- Students
- Teachers
- Parents
- Education levels
- Subjects
- Topics
- Educational resources
- Questions
- Answers
- Quizzes
- Quiz attempts
- Quiz results
- Weekly challenges
- Leaderboards
- Subscription plans
- Student subscriptions
- Payment records
- Notifications

## Planned Database Technologies

The project will evaluate:

- PostgreSQL
- MySQL

The final database technology will be selected during the backend development stage.

## Important Principle

The database must be designed so that:

- Student data is protected.
- Sensitive information is not exposed.
- Relationships between educational content are clear.
- The system can scale as EduVerse grows.
- Data can be backed up and restored.

## Planned Documentation

Future database documentation will include:

- Database schema
- Entity Relationship Diagram
- Table definitions
- Relationships
- Indexing strategy
- Migration files
- Seed data

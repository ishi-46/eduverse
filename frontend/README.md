# EduVerse Frontend

This directory contains the user interface of the EduVerse platform.

The frontend will eventually include:

- Landing page
- Login
- Registration
- Student dashboard
- Books
- Questions and Answers
- Quizzes
- Weekly challenges
- Leaderboards
- Progress tracking
- AI Tutor interface
- Profile
- Subscription interface

The frontend will be designed to work on:

- Mobile phones
- Tablets
- Laptops
- Desktop computers

The design will follow the EduVerse brand:

- Army Green
- Black
- White

**Motto:** ONE PLATFORM, FULL PACKAGE
